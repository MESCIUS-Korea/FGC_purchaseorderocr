# Forguncy 발주서 OCR 자동입력 데모

Forguncy(노코드 플랫폼)로 구현한 **영수증·발주서 OCR 자동입력** 데모입니다.
영수증이나 발주서 사진을 올리면 OCR이 텍스트를 추출하고, AI가 품목·수량·단가로 구조화해줍니다. 계산과 최종 저장은 검토 화면에서 사람이 원본과 대조한 뒤 진행됩니다.

## 🔗 데모 바로가기

👉 [데모 실행하기](https://demo.forguncy.co.kr/pro-upload)

## 🧩 핵심 포인트: 외부 OCR API 연동

이 데모는 Forguncy 자체 기능이 아니라, **Post 데이터 명령(HTTP POST)으로 외부 OCR 서비스인 OCR.space를 연동**해서 텍스트 인식을 구현했습니다.

- **처리 흐름**: 파일 업로드 → OCR.space 호출(원문 텍스트 추출) → AI 도우미 명령(품목 구조화) → 사람 검토 → 저장
- **핵심 원칙**: 계산과 최종 판단은 규칙(수식)으로 처리하고, AI는 텍스트 해석·구조화만 담당합니다.

## 📋 주요 기능

- 이미지·PDF 파일을 첨부하고 버튼 클릭으로 OCR 인식을 시작하는 단계별 업로드 화면
- Post 데이터 명령으로 외부 OCR API(OCR.space)를 연동한 원문 텍스트 자동 추출
- AI가 원문 텍스트를 공급업체명·품목·수량·단가로 구조화하는 자동 정리 기능
- 원본 스캔과 AI 인식 결과를 나란히 비교하며 확인하는 대조 검토 화면
- 규칙 기반 금액 계산과 AI 해석을 분리해 오류를 줄인 안전한 설계
- 검토대기·승인·반려 상태별로 확인하고 클릭 한 번으로 상세 검토로 이동하는 발주서 목록

## ⚠️ 실행 전 꼭 확인해주세요

다운로드한 프로젝트 파일(.fgko)은 보안상의 이유로 **AI 모델 연결 정보와 OCR API 키가 제거된 상태**로 배포됩니다. 그대로 실행하면 OCR 인식과 AI 구조화가 동작하지 않으니, 아래 두 가지를 먼저 설정해주세요.

1. **AI 모델 연결**: 파일 > 옵션 > 응용 프로그램 설정에서 AI 모델을 등록한 뒤, AI 도우미 명령에서 등록한 모델을 다시 선택
2. **OCR API 키**: [OCR.space 무료 키 발급](https://ocr.space/ocrapi/freekey) 후, `OCR_API` 서버단 명령의 Post 데이터 명령에 있는 `apikey` 값을 교체 (테스트용으로 `helloworld`를 임시 사용 가능하나 사용량 제한 있음)

## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. Post 데이터 명령을 통해 OCR.space 같은 외부 API와 손쉽게 연동하고, AI 도우미 명령으로 텍스트 구조화·해석 같은 지능형 기능까지 코딩 없이 구현할 수 있습니다.
